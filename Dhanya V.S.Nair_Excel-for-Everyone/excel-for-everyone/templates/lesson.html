What this browser practice supports

This is a focused answer checker, not a spreadsheet editor. Lessons 1–3 check a range address, key name or percentage. Lessons 4–5 accept formulas up to 160 characters using B2:B5, optional dollar signs, numbers, +, -, *, / and parentheses. Supported functions: SUM, AVERAGE, MIN, MAX and COUNT with one contiguous range inside B2:B5. No other cells, functions, uploads or macros are executed. Formula answers are tested on four input sets with a numeric tolerance of 0.00000001. Equivalent formulas that pass those sets are accepted; this is not a proof of equivalence for every possible input. Excel formatting and copying tasks need manual comparison with the solution workbook.
