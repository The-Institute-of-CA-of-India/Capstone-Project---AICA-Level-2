KNOW YOUR EXCEL

Different versions. Different possibilities.

The five ready lessons use long-established Excel features. The browser exercises work without Excel; downloaded workbooks are intended for Excel desktop or the web. Menus and shortcuts may differ on Windows and Mac. Examples use English function names and comma separators; local installations may use translated names or semicolons.

  • Lookups: XLOOKUP is unavailable in Excel 2016 and 2019. INDEX with MATCH is an alternative.
  • Dynamic arrays: FILTER, SORT, UNIQUE and SEQUENCE require a supported modern edition, such as Microsoft 365 or Excel 2021/2024. LET is available in modern editions; LAMBDA requires Microsoft 365 or Excel 2024.
  • Power Query: available in Excel 2016+ for Windows. Mac and web capabilities, connectors and editing depend on version and subscription; Excel 2016/2019 for Mac do not support it.
  • Power Pivot and DAX authoring: require a supported Windows desktop edition and licence. Mac and web do not offer the same authoring tools.
  • VBA and macros: require desktop Excel; VBA cannot run in Excel for the web. Mac supports VBA with platform differences. Only enable macros from trusted sources.
  • What-if tools, charts, slicers and collaboration: availability varies by platform, build, file format and licence. Check your edition before starting a future lesson. Real-time collaboration generally uses cloud storage and supported Excel versions.

Microsoft references: XLOOKUP · Power Query · LAMBDA
