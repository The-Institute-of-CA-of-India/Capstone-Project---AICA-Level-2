# Revenue Cut-off Testing Studio

**Author:** Vaishnavi Basutkar, Chartered Accountant  
**AICA Level II Capstone**

This Python and Streamlit app helps auditors compare ledger posting dates with delivery and shipment evidence. It reads scanned PDFs using local Tesseract OCR, flags evidence requiring review, and exports an Excel audit working paper.

## Run on 64-bit Windows

1. Extract the full submission ZIP.
2. Follow Tesseract_Download.txt if you need OCR for scanned documents.
3. Open Revenue_Cutoff_Testing_Studio and run Start_Revenue_Cutoff_Studio.bat. Python is bundled. The first launch requires internet access to install dependencies.
4. Follow START_HERE.txt to test the supplied evidence ZIP and dummy sales register in Sample_Data.

The exported sample working paper is in Sample_Results.
