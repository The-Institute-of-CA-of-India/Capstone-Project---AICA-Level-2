# Al-Mirsaad - UAE Business CRM

AICA Level-2 Capstone Project by Sheikh Anwar Hussain.

Al-Mirsaad is a UAE business directory and CRM platform built with TypeScript, React (Vite) and Firebase. It includes a business explorer, lead management, contacts directory, sales pipeline, analytics reports and AI-assisted data enrichment.

## Structure
- src/ - application source code (components, pages)
- server.ts - backend server
- data/ - sample business database
- docs/ - platform specification
- scripts/ - data ingestion scripts

## Setup
1. Install dependencies: bun install (or npm install)
2. Configure Firebase in firebase-applet-config.json and set environment variables
3. Run: bun run dev (or npm run dev)

See docs/UAE_PLATFORM_MASTER_SPECIFICATION.md for the full specification.
