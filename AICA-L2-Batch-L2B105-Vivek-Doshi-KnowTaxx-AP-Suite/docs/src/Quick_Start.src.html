AP & Expense Intelligence Suite: Quick Start

1. Install the server and note the admin password

Run KnowTaxx_AP_Suite_Server_Setup.exe as administrator and keep the default port, 5000. The last page shows the first sign-in details, so write them down. The server then runs as a Windows service.

2. Sign in and create your first client

  1. Open the KnowTaxx AP Suite desktop shortcut, or http://localhost:5000.
  2. Sign in and set your own password when asked.
  3. Go to Clients → New client. Enter the name, PAN and GSTIN, then save.

3. Share the vendor registration link

Copy the link from the client overview and send it to a vendor by WhatsApp or email. They fill in the form with no login. It arrives as Pending under Vendors for you to approve.

4. Upload your first invoice and see OCR in action

Open Upload invoice and drop in a PDF or photo. On the review screen, fields are colour-coded: green is high confidence, amber means check, red is low. Correct anything wrong and choose a cost centre.

5. Set up approval rules and approve on your phone

  1. Open Approval matrix and add a rule: an amount range, an approver and a level.
  2. On the invoice, press Submit for approval.
  3. The approver opens Pending on a phone and taps Approve, or swipes the card right.

To install the app on a phone or work offline, the server must run on HTTPS: python run.py --https. See User Guide section 13.

6. View your dashboard

Open Dashboard for spend, pending approvals, overdue payments and charts. Export to Excel, PDF or a Tally-ready CSV from the same page.
