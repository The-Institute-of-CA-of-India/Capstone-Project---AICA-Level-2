1. Introduction & system requirements

The AP Suite takes a vendor invoice from capture to payment for Indian CA firms and mid-size enterprises. It reads invoices with OCR, routes them through your approval rules, and reports on spend, budgets, aging and MSMED compliance. It runs on your own computer and network. Invoices are processed locally and no cloud service is used for core functions.

How an invoice moves through the system

StepWhoStatus afterwards
Captured by upload, camera or email, and read by OCRAnyone with upload rights, or automaticAuto Captured (high confidence) or Pending Review
Fields checked and corrected against the documentAccountantReviewed, then Pending Approval
Approved at every level the rules requireApproversApproved (or Rejected, or back to Pending Review on a query)
Payment recorded with UTR or referenceAccountantPaid

Server requirements

  • Windows 10 or 11, or Windows Server 2016 or later (64-bit). For development: any OS with Python 3.11 or later.
  • 4 GB RAM and 2 GB of disk to start. Allow about 1 GB for every 5,000 scanned invoices.
  • Tesseract OCR 5. The installer can include it; otherwise install it separately. Without it, files are stored but fields must be typed in.

User devices

  • Any current browser: Edge, Chrome, Firefox or Safari.
  • Phones: Android Chrome or iOS Safari on the same network as the server.

2. Installation

Server

  1. Run KnowTaxx_AP_Suite_Server_Setup.exe as administrator.
  2. Accept the install folder. Program files go to C:\Program Files\KnowTaxx AP Suite and your data to C:\ProgramData\KnowTaxx AP Suite.
  3. Choose a network port. Keep 5000 unless another program uses it.
  4. Note the first sign-in details on the last page.

The installer registers a Windows service named KTAPSuiteServer that starts with the computer, and opens the chosen port in the firewall for private and domain networks. The Start Menu folder has Open AP Suite, Stop Service, Start Service and Uninstall.

Client computers

A client computer needs no software, because the browser is enough. KnowTaxx_AP_Suite_Client_Setup.exe just adds shortcuts: enter the server's address and port, it tests the connection, and it creates a shortcut that opens the suite in its own Edge or Chrome window.

Running from source

pip install -r requirements.txt
python run.py

The app is then at http://localhost:5000. Add --port to change the port and --https for phone installation (see section 13). To load demonstration data, run python scripts/seed_demo_data.py.

Uninstalling asks before deleting your data. The default answer keeps it.

3. First login & password setup

  1. Open the suite and sign in with the temporary administrator details shown by the installer.
  2. You are taken straight to Change Password. Nothing else opens until you have set your own.
  3. Passwords need at least 8 characters, with at least one letter and one digit.

Good to know

  • Five wrong passwords lock the account for 15 minutes. An administrator can unlock it sooner from the Users page.
  • Sessions end after 10 hours.
  • Every sign-in, sign-out and data change is written to the audit log.

4. Client management

Create a client

Go to Clients → New client (administrators and managers). The code (C0001, C0002 and so on) is automatic. PAN is checked for format, and GSTIN for format and check digit.

Each new client automatically receives a vendor registration link and an email alias such as c0001.

Switching client

The dropdown at the top of every page switches the active client. The sidebar then shows that client's vendors, invoices and reports.

Archive and restore

Archiving hides a client without deleting anything, and stops its vendor link. Use Show archived on the client list to find and restore it.

5. Vendor management & self-registration

Add a vendor yourself

Vendors → New vendor. A vendor you add is active immediately. PAN is required, and a GSTIN must contain that same PAN.

Let the vendor register

  1. Copy the link from the client overview and send it by WhatsApp or email.
  2. The vendor opens it on any device, with no login, and fills in business, bank and contact details.
  3. They attach a PAN card copy and cancelled cheque, plus a GST certificate if they have a GSTIN, and optionally an MSME certificate.
  4. The record arrives as Pending with a badge in your sidebar.
  5. Check the documents, then press Approve vendor.
If a link has reached the wrong person, press Generate a new link on the client overview. The old link stops working at once.

Duplicate detection

Before saving, the suite looks for an existing vendor with the same PAN, the same GSTIN, or a name more than 80% similar. You see the matches and must tick a box to save anyway. On the public form, matches are never shown to the vendor; they are noted on the pending record for you.

Blacklisting

A blacklisted vendor needs a reason, and their invoices cannot be submitted for approval. A change of bank details is recorded in the audit log, so check it against a cancelled cheque before paying.

6. Invoice capture

Upload

Open Upload invoice and drag files on, or choose them. PDF, JPG and PNG are accepted, up to 20 MB each, and several at once. The first 10 pages of a PDF are read.

Camera

On a phone, a large Take Photo button opens the camera. For the best OCR: flat page, good light, whole invoice in frame, no shadow across the numbers.

Email

Once an administrator connects a mailbox (section 15), the suite checks it for unread mail. PDF and image attachments become invoices, and sender, subject and date are stored with them. The vendor is matched by the GSTIN on the document, or else by sender address or company domain.

Using plus-addressing, a single mailbox can serve every client:

knowtaxxap+c0001@gmail.com  → Client C0001
knowtaxxap+c0002@gmail.com  → Client C0002

Duplicate protection

Uploading the same file twice for a client flags the second as a possible duplicate, as does the same invoice number, vendor and amount.

7. OCR review & correction

Nothing goes for approval until a person has reviewed it. Open an invoice from Invoices → To review.

Reading the colours

ColourLabelMeaning
GreenHighConfidence above 0.8. For example, the GSTIN passed its check digit, or the amounts add up.
AmberCheckConfidence 0.5 to 0.8. Probably right, but compare it with the document.
RedLowBelow 0.5, or nothing was found.

Working through the screen

  1. Compare the fields with the document. Use + and − to zoom, or Ctrl and the mouse wheel.
  2. Accept All restores every value OCR read, if you have changed something and want to go back.
  3. Link the vendor if it is not already linked. If it is unknown, use Register this vendor.
  4. Watch the Arithmetic check: taxable value plus taxes must match the total within ₹1.
  5. Choose the category, cost centre and GL ledger. Check any suggested TDS section and rate.
  6. Press Submit for approval, or Save for later to return to it.
Category and TDS are rule-based suggestions and must be confirmed. Section labels use the familiar Income-tax Act 1961 numbers (194C, 194J and so on), which from 1 April 2026 are consolidated in section 393 of the Income-tax Act 2025. Check the applicable rate and any threshold yourself.

What OCR read is kept beside what you corrected, and the raw OCR text stays at the bottom of the page for audit.

8. Approval workflow

Setting the rules

A rule sets an amount range, optionally a category and a cost centre, an approver and a level. Level 1 approves first, then level 2. For example, ₹10,001 to ₹1,00,000 might go to a Finance Manager at level 1 and the CFO at level 2.

If several rules fit one level, the most specific wins. If no rule fits an invoice, it stays Reviewed and you are told to add one.

Deciding

ActionResult
Approve (or swipe right)Moves to the next level, or to Approved after the last level.
Reject (or swipe left)Needs a reason. The status becomes Rejected, and this is final.
QueryNeeds your question. The invoice returns to the accountant as Pending Review, showing the question.

Approvers see only their own queue. Administrators and managers see everything and can act on any invoice, which is recorded under their name.

Turnaround tracking

The Pending page and the dashboard show average approval time and the number of invoices waiting more than 24, 48 and 72 hours.

Paying

Open an approved invoice and use Record payment with the date and UTR. Payment itself is made through your bank; the suite only records it.

9. Cost centre management

Open Cost centres in the sidebar. Each has a code and a name, and can sit under a parent to form a tree, such as Sales with North and South beneath it.

Assign the cost centre on the review screen. Inactive centres stay in old reports but cannot be chosen for new invoices.

The report shows spend directly on a centre, and with its children added. Invoices with no cost centre appear as Unallocated, so nothing goes missing. Amounts here are taxable value, excluding GST.

10. Reports & dashboards

Dashboard

  • KPI cards: invoices and amount this month, pending approvals, overdue payments.
  • Charts: monthly spend for 12 months, spend by category, top 10 vendors, approval status by month.
  • What counts as spend: reviewed invoices onward. Captured-but-unreviewed, rejected, cancelled and flagged duplicate invoices are left out, so OCR guesses never reach your figures.

AP aging and MSMED

Open invoices fall into Current, 1-30, 31-60, 61-90 and 90+ days past due. If an invoice has no due date, the suite assumes 30 days from the invoice date, or 45 for an MSME vendor.

The MSMED view lists open invoices from MSME vendors against the 45-day maximum in section 15 of the MSMED Act, counted from the invoice date. They are flagged Approaching from day 30 and Past 45 days after that. If you have a different date of acceptance or a shorter agreed period, allow for it.

11. Variance analysis

Enter budgets on the Budgets page: one amount per cost centre per month. Then open Variance analysis and choose a month.

Traffic lights

LightMeaning
GreenWithin 5% of budget, or under budget
Amber5% to 15% over budget
RedMore than 15% over budget, or spend with no budget

Actuals exclude GST

Actuals use taxable value, because GST is normally recoverable as input credit. If GST on a type of spend is blocked, budget for it accordingly.

Commentary

The suite writes a short note on the three largest overspends, naming the largest vendor and category behind each. It is produced by rules from your invoice data. It identifies where the money went, not why, so confirm the reason before passing it on.

Period comparison

A second table compares this month with last month, and this quarter with the same quarter last year, using Indian financial-year quarters.

13. Mobile app (PWA installation)

Phones need HTTPS. Browsers allow app installation and offline mode only on https:// or on the computer itself (localhost). On a plain http://192.168... address a phone can use every online feature, but it cannot install the app or work offline. Start the server with python run.py --https and open the https:// LAN address. It uses a self-signed certificate, so the phone warns the first time; on iOS, install and trust the certificate for the app to install.

Android (Chrome)

  1. Open the server's https:// address and sign in.
  2. Open the ⋮ menu and tap Install app or Add to Home screen.

iPhone or iPad (Safari)

The suite shows these steps on your first visit:

  1. Tap the Share button.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add.

Alerts

Tap Enable alerts on the Pending page. While the app is open, it checks every minute and notifies you of new approvals. There is no background push when the app is closed, because that would need an internet service.

14. Offline mode & sync

Away from the office network, the installed app opens its offline page. Sign in once while connected first, so the device holds your client list and pending approvals.

What you can do offline

  • Capture: photograph an invoice and add the vendor, amount and a note.
  • Approvals: approve or reject from the last snapshot.
  • Queue: see what is waiting.

When you reconnect

Queued items sync automatically, or with Sync now. The server runs OCR on captured photos and applies your decisions. A message confirms the result, such as "3 items synced, 1 conflict". If your session has expired, you are asked to sign in first and the items wait.

Conflicts

If an invoice changed while you were offline, for example because a manager approved it, your decision is not applied. It is marked as a conflict on your device and listed for managers on the Pending page to review and mark as resolved.

Signed-in pages are not stored in the browser cache. The device keeps only your client names, your pending approvals and your queued items. Signing out removes the cached names and approvals. Queued items stay so unsynced work is not lost.

Users and roles

RoleCan do
AdminEverything, including users, email settings and backups
ManagerAll clients, approvals, approval rules, reports, audit log
AccountantAssigned clients: vendors, review, reports, exports
ApproverOwn approval queue only
Field staffUpload invoices for assigned clients; see own uploads

Assign clients to accountants and field staff on their user page. The last active administrator cannot be demoted or deactivated.

Email ingestion

  1. For Gmail, turn on 2-Step Verification and create an App Password. Your normal password will not work.
  2. Enter imap.gmail.com, port 993, the address and the App Password. It is stored encrypted.
  3. Press Test connection, tick Listener active, and save.

A message is marked as read only after its invoices are saved, so a failure does not lose it. Errors show in the status table. The poller is the one feature needing internet access.

Audit log

Backup

The backup covers the database only. Also copy data/files (your invoices) and instance/secret_key.txt (without it, saved email passwords cannot be read). Keep copies away from the server.

To restore: stop the service, replace instance/apsuite.db with the backup file, and start the service.

16. Troubleshooting

ProblemWhat to do
"Tesseract OCR is not installed" on the upload pageInstall Tesseract 5 and restart, or set the TESSERACT_CMD environment variable to the full path of tesseract.exe. Backup & system shows whether it was found.
Fields read poorlyRetake with better light and a flat page. Scanning at 200-300 DPI works best. Low-confidence fields are marked, so correct them on the review screen.
Other devices cannot connectCheck both are on the same network. Use the server's IP address, not localhost. Allow the port through the firewall. Check that the service is running.
Phone will not install the app or has no offline pageThe server must be on HTTPS: see section 13.
"No approval rule matches"Add a rule covering that amount, category and cost centre. Check that the approver's account is active.
Account lockedWait 15 minutes, or an administrator presses Unlock on the Users page.
"Session expired" on a formThe page was open a long time. Refresh it and try again.
Email not being capturedSee the status table on the Email ingestion page. For Gmail, use an App Password and enable IMAP. Only unread mail with PDF, JPG or PNG attachments is processed.
Vendor link does not open for the vendorThe link works only on your network unless your IT team exposes the server. Have the vendor connect to office Wi-Fi, or capture the details yourself with New vendor. If you expose it to the internet, use HTTPS and take IT advice first.
Tally import rejects ledgersCreate the ledgers in Tally with exactly the same names, or set the GL account on each invoice to match.
Saved email password stops working after a restoreRestore instance/secret_key.txt too, or re-enter the password.
Port 5000 already in usepython run.py --port 5050, or choose another port when installing.

Logs for the Windows service are in C:\ProgramData\KnowTaxx AP Suite\logs.
