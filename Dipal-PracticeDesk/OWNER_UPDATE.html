Enable automatic faculty setup

This is a one-time owner update. Faculty use START.html; they do not perform these steps.

  1. Open your existing Google Apps Script project.
  2. Copy the complete updated Index.html below and replace the existing Index.html content. Save. Keep the corrected Code.gs and existing manifest.
  3. Choose Deploy → Manage deployments → Edit → New version → Deploy. Update the existing deployment; do not create a different URL.
  4. Open the existing /exec link in a second Google account. After authorization, confirm that its database is created automatically.
  5. Test saved-state reload and a self-addressed email before assessment.
