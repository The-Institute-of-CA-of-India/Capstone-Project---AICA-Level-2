## Upload workflow after confirming the destination

1. Sign in to your GitHub account and fork the confirmed repository.
2. Extract this ZIP. Drag the entire **Dipal-PracticeDesk** folder into your fork using Add file → Upload files. Do not upload only the ZIP archive, and do not place the individual files at repository root.
3. Confirm the uploaded path is `Dipal-PracticeDesk/README.md` and the original repository files remain unchanged.
4. Commit with: `Add Dipal - PracticeDesk AICA Level 2 capstone`.
5. From the fork, choose Contribute → Open pull request.
6. Verify base repository = the confirmed official destination, base branch = main, and head repository = your fork.
7. Use the title and body in PR_DESCRIPTION.md.
8. Save the resulting PR URL as the submission record. Merge/review belongs to the repository maintainers.

The folder has no nested .git directory and no credentials, dependency folders or real client datasets. It contains fewer than 100 files and all are below 100 MB.
