---
description: 13-week cash forecast for a scenario (base, late_15, top_customer_default, capex_forward)
argument-hint: "[scenario]"
---

Call the `cashsense` MCP tool `forecast` with scenario "$ARGUMENTS" (use "base" if empty). Report the peak CC
drawing and utilisation, the week it occurs, the first week above the 85% alert (or "none"), and a weekly table
(week, ending date, net flow, CC drawn, utilisation). State that it is an estimate based on CashSense's assumptions.
