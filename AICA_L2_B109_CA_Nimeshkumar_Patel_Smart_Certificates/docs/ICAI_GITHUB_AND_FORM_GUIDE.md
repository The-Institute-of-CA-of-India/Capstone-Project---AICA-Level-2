# ICAI GitHub and Google Form Submission — Step by Step

**Official form:** https://docs.google.com/forms/d/e/1FAIpQLScouYmLe7KzQb93dbctDkiCYPeMxRpmpjDb2fWfPLGD4qmYkw/viewform?pli=1

**Official repository:** https://github.com/aiinicai/AICA-Level-2-Projects

**Official manual linked in form:** https://drive.google.com/file/d/17VfaXRD4b3QVydPmHkHj8wbDdpp9sy1f/view?usp=drive_link

The form requires submission of the capstone project **and demonstration video within 10 days of batch completion**. Confirm your own deadline. The linked Google Drive PDF could not be fully inspected in this preparation; the public official GitHub repository README does describe the Fork + Pull Request workflow.

## A. Prepare
1. Extract this ZIP; keep the project folder intact. Do not include real client data or SQLite database.
2. Run and test V54 using demonstration data; check four certificates, imports and Word outputs.
3. Capture anonymised screenshots and save in `screenshots/` (currently empty).
4. Build Windows EXE if desired; not a separate requirement shown in the form.

## B. Upload to ICAI's repository (website-only method)
1. Sign in to GitHub, open the official repository above.
2. Click **Fork** and create your copy under your own GitHub account.
3. In your fork click **Add file > Upload files**.
4. Drag the **whole project folder** `AICA_L2_B109_CA_Nimeshkumar_Patel_Smart_Certificates` into the uploader. Check the folder paths are preserved. Do not upload `.venv`, `dist`, databases or client documents.
5. Click **Commit changes** with message `Add Batch 109 CA Nimeshkumar Patel Smart Certificates capstone`.
6. In your fork choose **Contribute > Open pull request**.
7. Verify **base** `aiinicai/AICA-Level-2-Projects:main`, **head** `YOUR-USERNAME/AICA-Level-2-Projects:main`.
8. Add a descriptive PR title and summary, click **Create pull request**.
9. Copy the Pull Request URL and project-folder URL. ICAI repository owners review/merge; do not claim acceptance until merged.

## C. Record demonstration video
1. Use screen recording with a webcam view that shows your face and the application demonstration (the form says facial expression and technical content).
2. Show project objective, tech stack, client setup, ITR import, turnover/net worth review, Word output and GitHub source.
3. Use synthetic/redacted data; do not expose actual client PAN, GSTIN, bank accounts, UDIN or contact information.
4. Upload to YouTube as **Unlisted**, or Google Drive set to **Anyone with the link – Viewer**.
5. Test the link in an incognito window.

## D. Submit Google Form
Enter registered email, full name, batch **109** (numeric only), membership **165969**, phone, registered email, title, description, video URL, and GitHub project URL. Read the declaration: it includes consent to ICAI ownership/publication. Submit and save confirmation.

## Important
A personal repository alone is not the same as a contribution to ICAI's official repository. Follow the Fork + PR instructions and ask faculty if they prefer PR URL or project-folder URL before the PR is merged.
