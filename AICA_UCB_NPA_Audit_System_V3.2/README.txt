UCB NPA AUDIT SYSTEM V3.2

1. Extract this folder.
2. Run Run_Application.bat.
3. Upload UCB_NPA_Single_Workbook_Input_and_Samples.xlsx once.
4. The app reads Primary Loan Dump, Daily Position, Transactions, Security and NPA History from the same workbook.
5. Download the report and review Provision Review, Annex I Summary and Verification.

Important limitations:
- Prototype for audit assistance; not an RBI compliance certification tool.
- CC/OD test indicators require complete consecutive 90-day daily positions and complete transactions; missing dates/records must be investigated.
- Security realisable value is a data input and must be validated for enforceability, valuation date, prior charges and eligibility.
- Special guarantee, deposit-backed, fraud, project-finance and resolution-plan provisions need separate review and are not fully automated.
- Annex I book figures (provision held, interest suspense, claims, suspense receipts) require manual inputs from audited books; blanks are intentional, not zero.
- Keep V3.0/V3.1 backups.
